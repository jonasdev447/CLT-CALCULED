# 💰 CONTROL SPENT — Controle de Finanças

Programa simples e prático pra organizar suas contas, gastos e investimentos mensais.

## Funcionalidades
- ✅ Salário / Orçamento total
- ✅ Lista de gastos fixos e variáveis
- ✅ Dois campos para investimentos
- ✅ Cálculo automático do saldo disponível
- ✅ Aceita SOMENTE números — letras não aparecem!

## Tecnologia
- Python + Tkinter
